## Summary

Gbam CLI is a versatile command-line tool designed to simplify your development workflow. Key features include:

- **File Referencing**: Use "@" to reference shared modules and packages easily.
- **Modes of Operation**: The CLI operates in different modes, allowing for various functionalities depending on your needs.
- **Comprehensive Command Options**: Execute a wide range of commands to manage your projects effectively.

For installation and further details, refer to the additional sections.

## Installation

To install the Gbam CLI, run the following command:

```bash
npm install -g gbam-dev
```

## Usage

To start using Gbam CLI, run:

```bash
gbam 
```
